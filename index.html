01 / CREATIVE BRIEF

Diseñar para una industria compleja sin hacerla distante.

La oportunidad no era llenar la pantalla de petróleo, maquinaria y efectos. Era construir confianza: explicar la capacidad técnica con una jerarquía visual que un decisor pueda recorrer rápido.

A / CONTEXTO

Infraestructura energética integral

Coastoil Dynamic comunica compresión, tratamiento, deshidratación, eliminación de hidrocarburos y Gas LP dentro de una misma cadena de valor.

Lectura de marca: rigor + continuidad.
B / AUDIENCIA

Personas que aprueban proyectos

Dirección, ingeniería, operaciones, compras y socios estratégicos necesitan evidencia, no solo una estética “industrial”.

Diseño: datos visibles + lenguaje claro.
C / OPORTUNIDAD

Convertir capacidad en narrativa

El sistema usa líneas de flujo como recurso visual para conectar proyectos, procesos, seguridad y sustentabilidad.

Promesa: confianza que avanza.

Una identidad que se comporta como infraestructura.

La propuesta combina una base técnica y sobria con un color señal para marcar movimiento, datos y llamados a la acción.
