# Brand rationale

## Idea visual

El sistema se construye con una tensión controlada: una base **Deep Current** sobria para comunicar ingeniería y una señal **Process Teal** que da continuidad a los procesos. El **Signal Amber** aparece en puntos de decisión, no como decoración permanente.

## Logotipo conceptual

El monograma CD se forma con dos recorridos conectados. La primera forma sugiere una C abierta y la segunda una D estructurada; juntas parecen tubería, circuito y flujo. El punto ámbar funciona como indicador de estado.

## Paleta

| Color | Hex | Uso |
| --- | --- | --- |
| Deep Current | `#0B1724` | fondos, titulares, presentaciones |
| Process Teal | `#1FB7A6` | líneas de flujo, enlaces, estados positivos |
| Signal Amber | `#F5A623` | CTA, datos clave, alertas visuales |
| Warm Sand | `#E9E1D2` | fondos editoriales, infografías, pausas visuales |

## Tipografía

- Display: Barlow Condensed o una sans condensada equivalente para titulares técnicos y memorables.
- Texto: Inter, Arial o una sans accesible para lectura en web y documentos.
- Datos: monospace para unidades, códigos, indicadores y etiquetas de sistema.

## Reglas de composición

1. Un dato principal por pieza.
2. Una sola llamada a la acción.
3. Las líneas de flujo deben conducir la mirada, no competir con el mensaje.
4. La imagen de maquinaria se usa como evidencia, nunca como sustituto del contenido.
5. El sistema debe sobrevivir en una presentación, una publicación y un email.

## Lo que evitaría

Gradientes azules genéricos, llamas de stock, exceso de brillos, fotografías sin contexto, párrafos largos dentro de anuncios y cifras sin fuente o fecha.
