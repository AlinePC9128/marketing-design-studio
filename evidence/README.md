# Carpeta de evidencia

Esta carpeta convierte el proyecto en una evidencia defendible durante una entrevista. La estructura muestra proceso, criterio y producción; no solo el resultado final.

## Archivos

1. [Creative brief](creative-brief.md) — problema, audiencia, mensaje y alcance.
2. [Brand rationale](brand-rationale.md) — decisiones de marca, color, tipografía y composición.
3. [Deliverables](deliverables.md) — formatos, dimensiones y posibles usos.
4. [Analytics and optimization](analytics-and-optimization.md) — hipótesis, eventos y KPI.
5. [Role alignment](role-alignment.md) — relación con la experiencia real de Aline.
6. [Content and copy](content-copy.md) — mensajes por etapa del funnel.

## Cómo presentarlo

Explicar el caso en este orden: contexto → decisión visual → piezas → medición → siguiente iteración. La frase clave es: “No diseñé una pieza aislada; construí un sistema que puede vivir en ventas, contenido, email y campañas”.
