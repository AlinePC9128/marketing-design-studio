# Carpeta de evidencia

Esta carpeta convierte el portafolio en una evidencia defendible durante una entrevista. Muestra proceso de marca, criterio visual, producción, documentación y medición, no solamente imágenes terminadas.

## Archivos

1. [Brief creativo](creative-brief.md) — contexto, audiencia, reto y alcance del caso conceptual.
2. [Razonamiento de marca](brand-rationale.md) — dirección editorial, color, tipografía, composición y sistema.
3. [Entregables](deliverables.md) — formatos, dimensiones y producción de aplicaciones.
4. [Analítica y optimización](analytics-and-optimization.md) — hipótesis, eventos y KPI.
5. [Relación con vacantes](role-alignment.md) — conexión con la experiencia comprobada.
6. [Contenido y copy](content-copy.md) — mensajes y llamados a la acción.
7. [Perfil ATS](ats-profile.md) — perfil de reclutamiento y palabras clave.
8. [Dirección visual 2026](trends-2026.md) — tendencias consultadas y decisiones aplicadas.

## Referencias profesionales

La carpeta visual de `assets/professional/` reúne nueve piezas proporcionadas por Aline como evidencia de trabajo para [Intersyst Seguridad y Control](https://intersyst.com.mx/) y [AUTOSISE](https://autosise.com.mx/). Se muestran como producción profesional: campañas, comunicación de producto, infografías y piezas educativas.

El relato correcto para entrevista es: “Desarrollé la propuesta visual desde el contexto del producto y el objetivo de comunicación. Cuando utilicé IA, fue como apoyo para investigar, idear o explorar imágenes; la dirección de arte, la composición, la consistencia, la adaptación y la revisión final fueron humanas”.

## Orden para entrevista

Explicar el trabajo en este orden: contexto → decisión visual → entregables → medición → siguiente iteración.

La idea central es: “No hice una pieza aislada; construí un sistema visual que puede vivir en logotipo, contenido, email, web y campañas”.

La galería de disciplinas contiene ejemplos conceptuales creados para demostrar alcance visual. No se presentan como trabajos oficiales de clientes ni sustituyen la evidencia profesional de Intersyst y AUTOSISE.

Las exploraciones de `assets/identity-2026/` son conceptos de marca minimalistas para mostrar cómo trabajo un logo: símbolo, retícula, versiones monocromáticas, escalabilidad y aplicaciones. La lámina `marcas-mexicanas-minimalistas.svg` reúne seis ejercicios ficticios de ilustración lineal, nombre y descriptor; no representa una categoría comercial ni trabajos de clientes. La carpeta `assets/rebranding-autosise/` documenta el rebranding de AUTOSISE con la secuencia correcta: logo anterior de tres picos, logo actualizado horizontal y sistema de aplicación.
